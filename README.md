# Football Manager Game (working title)

Mobile-first (iOS + Android) football management simulation.

**Design brief:** the simplicity of FC Chairman / FC Pro 2, the breadth of options
of old FIFA Manager career mode. Explicitly NOT Football Manager depth.
Unlicensed, but as close to real football as is legally safe.
UI must be usable by someone who has never played a management game.

## Repo layout

- `docs/research/` — agent research output (one file per discipline)
- `docs/` — the synthesised design bible
- `prototype/` — playable vertical slice (zero-build static web, opens on a phone)
- `src/data/` — world data (fictional clubs, leagues, name pools)
